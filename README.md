# open-proxy-rulesets

Unified proxy rulesets for **Mihomo**, **sing-box**, and **Surge**.

## Sources

- [DustinWin/domain-list-custom](https://github.com/DustinWin/domain-list-custom): fused and deduplicated domain rules for `AI`, `Ads`, `AppleCN`, `CN`, `Download`, `GamesCN`, `GlobalMedia`, `Private`, `Proxy`, `Speedtest`, `TikTok`, and `YouTube`.
- [MetaCubeX/meta-rules-dat](https://github.com/MetaCubeX/meta-rules-dat): categories not provided by DustinWin, plus `PrivateIP` and `TelegramIP`.
- [nekolsd/geoip](https://github.com/nekolsd/geoip): `CNIP`.

## Generated outputs

- `mihomo/*.mrs`
- `sing-box/*.srs`
- `surge/*.list`

Updated automatically every 24 hours.
